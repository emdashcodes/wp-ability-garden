# 2. Getting Started

## Installation

### WordPress 6.9+

The Abilities API is included in WordPress 6.9 core. No additional installation is required.

### WordPress < 6.9

For earlier versions, you must install the Abilities API before use.

#### As a plugin

Install from the [GitHub Releases page](https://github.com/WordPress/abilities-api/releases/latest).

##### With WP-CLI

```bash
wp plugin install https://github.com/WordPress/abilities-api/releases/latest/download/abilities-api.zip
```

##### With WP-Env

```jsonc
// .wp-env.json
{
  "$schema": "https://schemas.wp.org/trunk/wp-env.json",
  "plugins": [
    "WordPress/abilities-api"
  ]
}
```

#### As a Plugin Dependency (Recommended)

Include it in your plugin's `Requires Plugins` header:

```diff
# my-plugin.php
/*
 * Plugin Name:       My Plugin
 * Plugin URI:        https://example.com/plugins/the-basics/
 * Description:       Handle the basics with this plugin.
+ * Requires Plugins:  abilities-api
 */
```

#### As a Composer dependency

```bash
composer require wordpress/abilities-api
```

### Checking availability with code

Check if the API is available:

```php
if ( ! class_exists( 'WP_Ability' ) ) {
  add_action( 'admin_notices', static function() {
    wp_admin_notice(
      esc_html__( 'This plugin requires the Abilities API. Please install and activate it.', 'my-plugin' ),
      'error'
    );
  } );
  return;
}
```

Check for specific versions:

```php
if ( ! defined( 'WP_ABILITIES_API_VERSION' ) || version_compare( WP_ABILITIES_API_VERSION, '0.1.0', '<' ) ) {
  add_action( 'admin_notices', static function() {
    wp_admin_notice(
      esc_html__( 'This plugin requires Abilities API version 0.1.0 or higher.', 'my-plugin' ),
      'error'
    );
  } );
  return;
}
```

## Basic Usage Example

```php
<?php

// 1. Register a category first (required before registering abilities)
add_action( 'wp_abilities_api_categories_init', 'my_plugin_register_categories' );

function my_plugin_register_categories() {
    wp_register_ability_category( 'site-info', array(
        'label'       => __( 'Site Information', 'my-plugin' ),
        'description' => __( 'Abilities that retrieve site information.', 'my-plugin' ),
    ) );
}

// 2. Register the ability when the Abilities API is initialized.
add_action( 'wp_abilities_api_init', 'my_plugin_register_abilities' );

function my_plugin_register_abilities() {
    wp_register_ability( 'my-plugin/get-site-title', array(
        'label'               => __( 'Get Site Title', 'my-plugin' ),
        'description'         => __( 'Retrieves the title of the current WordPress site.', 'my-plugin' ),
        'category'            => 'site-info',
        'input_schema'        => array(
            'type'                 => 'object',
            'properties'           => array(),
            'additionalProperties' => false,
        ),
        'output_schema'       => array(
            'type'        => 'string',
            'description' => 'The site title.',
        ),
        'execute_callback'    => function() {
            return get_bloginfo( 'name' );
        },
        'permission_callback' => '__return_true',
        'meta'                => array(
            'show_in_rest' => true,
        ),
    ) );
}

// 3. Later, retrieve and execute the ability.
add_action( 'admin_init', 'my_plugin_use_ability' );

function my_plugin_use_ability() {
    $ability = wp_get_ability( 'my-plugin/get-site-title' );
    if ( ! $ability ) {
        return;
    }

    $site_title = $ability->execute();
    if ( is_wp_error( $site_title ) ) {
        error_log( 'Execution error: ' . $site_title->get_error_message() );
        return;
    }

    echo 'Site Title: ' . esc_html( $site_title );
}
```
